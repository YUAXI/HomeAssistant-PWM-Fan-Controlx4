# 实体参考

[← 首页](Home) · **中文** · [English](Entities-EN)

固件里每个 `name` 都会变成 HA 中的一个实体，同时出现在 Web 面板和 REST API 中。本页是完整的实体清单与默认值。

## 命名规则

| 层级 | 示例 |
|:-----|:-----|
| 配置文件里的 `name` | `风扇 1` |
| Web / REST API 里的实体名 | `风扇 1`（与 YAML 完全一致，含空格和中文） |
| HA 设备名 | `ESP32 PWM 22810 a1b2c3` |
| HA `entity_id` | `fan.esp32_pwm_22810_a1b2c3_风扇_1` |

- HA 的 `entity_id` = 设备名 + 实体名再做 slug 化，中文会被保留。
- 不同固件、不同设备名的实际 `entity_id` 可能不同，**以 HA 实体页面显示为准**；可以在 HA 中手动改 `entity_id`，不影响固件。
- 想彻底避免中文 ID，可在配置里把 `name` 改成 ASCII（见 [固件版本](Firmware#自定义编译)）。

## 风扇（fan）

| 实体名 | 固件内 id | 说明 |
|:-------|:----------|:-----|
| 风扇 1 | `my_fan1` | PWM = GPIO16，电源 = GPIO21 |
| 风扇 2 | `my_fan2` | PWM = GPIO17，电源 = GPIO22 |
| 风扇 3 | `my_fan3` | PWM = GPIO18，电源 = GPIO23 |
| 风扇 4 | `my_fan4` | PWM = GPIO19，电源 = GPIO13 |

| 属性 | 值 |
|:-----|:---|
| 类型 | `speed`（带档位调速） |
| 档位数 | `speed_count: 100` → 速度等级 1–100 |
| 上电恢复 | `RESTORE_DEFAULT_OFF`（默认关） |
| 开 | 打开 TPS22810 负载开关给风扇供电，再输出 PWM |
| 关 | 先停 PWM，再切断负载开关（真正断电，不是 0% 占空比） |
| 关闭时的转速 | 转速会掉到 0（风扇断电） |

> 4 个电源开关（`fan1_pwr`–`fan4_pwr`）是 `internal: true`，**不会**出现在 HA / Web / API 里，由风扇实体自动联动。

## 传感器（sensor）

| 实体名 | 单位 | 刷新 | 适用固件 | 说明 |
|:-------|:-----|:-----|:---------|:-----|
| 风扇 1 转速 | RPM | 4s | 全部 | `pulse_counter`，下降沿计数 |
| 风扇 2 转速 | RPM | 4s | 全部 | 同上 |
| 风扇 3 转速 | RPM | 4s | 全部 | 同上 |
| 风扇 4 转速 | RPM | 4s | 全部 | 同上 |
| 温度 A | °C | 5s | DS18B20 / 雷达 | 1-Wire 索引 0 |
| 温度 B | °C | 5s | DS18B20 / 雷达 | 1-Wire 索引 1 |
| 温度 C | °C | 5s | DS18B20 / 雷达 | 1-Wire 索引 2 |
| 温度 D | °C | 5s | DS18B20 / 雷达 | 1-Wire 索引 3 |
| 雷达目标距离 Dist | m | 事件驱动 | 雷达 | 无人/超范围时发布 `NaN`（HA 显示 unknown） |
| 设备运行时间 | s | 60s | 全部 | 诊断实体 |
| Wi-Fi 信号强度 | dBm | 60s | 全部 | 诊断实体 |

转速换算：风扇每转输出 **2 个**转速脉冲，固件用 `multiply: 0.5` 把「每分钟脉冲数」换算成 RPM。若某风扇实际是 1 脉冲/转，读数会偏低一半，可在配置里改 `multiply`。

## 参数（number）

### 温控参数（每路风扇 4 个，共 16 个）

| 实体名格式 | id | 范围 | 步长 | 默认 | 单位 |
|:-----------|:---|:-----|:-----|:-----|:-----|
| 风扇N 启控温度 T-Min | `fN_t_min` | 10–60 | 1 | 30 | °C |
| 风扇N 满载温度 T-Max | `fN_t_max` | 40–90 | 1 | 50 | °C |
| 风扇N 最低风速 F-Min | `fN_f_min` | 0–50 | 1 | 0 | % |
| 风扇N 最高风速 F-Max | `fN_f_max` | 50–100 | 1 | 100 | % |

`N` 取 1–4。全部 `restore_value: true`，掉电保持。

### 雷达参数（仅雷达固件，2 个）

| 实体名 | id | 范围 | 步长 | 默认 | 单位 |
|:-------|:---|:-----|:-----|:-----|:-----|
| 雷达 最近过滤门限 Min | `radar_min_dist` | 0.0–2.0 | 0.05 | 0.10 | m |
| 雷达 最远过滤门限 Max | `radar_max_dist` | 0.5–8.0 | 0.1 | 1.5 | m |

|:-------|:---|:-------|:-----|

## 掉电保持与恢复

| 数据 | 存储位置 | 行为 |
|:-----|:---------|:-----|
| 温控参数、雷达门限 | ESP32 NVS | `restore_value: true`，重启后保留 |
| 温度源绑定 | NVS | 同上 |
| 风扇开关/速度 | 不保存 | 每次上电都是关闭状态（`RESTORE_DEFAULT_OFF`） |
| Wi-Fi 凭据 | NVS | 保留；连不上会回落到热点 |

> 正常 OTA 升级会保留 NVS；用 `.factory.bin` 全片刷写（含分区表）会清空参数回到默认值。

## 找不到某个实体？

1. **诊断类实体**在 HA 里被折叠到设备的「诊断」区域，不在主控制卡片中；
2. `internal: true` 的实体永不暴露（只有 4 个电源开关）；
3. 温度 / 雷达 / 参数类实体只存在于对应固件，Basic 与 v1.0 没有；
4. 实体名重复时 HA 会加 `_2` 后缀，可在实体列表搜索「风扇」确认。
