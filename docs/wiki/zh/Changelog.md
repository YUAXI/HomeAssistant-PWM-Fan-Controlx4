# 更新记录

[← 首页](Home) · **中文** · [English](Changelog-EN)

本页记录固件与硬件的行为变更。**标记 ⚠️ 的条目会改变设备在 Home Assistant 中的表现，升级前请阅读。**

## 固件

| 日期 | 变更 | 影响 |
|:-----|:-----|:-----|
| 2026-10-14 | 全版本启用 `name_add_mac_suffix: true` | ⚠️ 设备名变为 `esp32pwm22810-<mac3>`，`entity_id` 全部变化；旧条目需删除后重新添加。好处是同一份固件可刷多台设备并同时接入 HA |
| 2026-08-16 | 温度 ≤ `T-Min` 时**断电完全停转**，温度恢复后自动重启 | ⚠️ 低温下风扇从「低速常转」变为「彻底停转」；偏好常转的用户请把 `T-Min` 调低或把 `F-Min` 提高后自行判断 |
| 2026-07-10 | DS18B20 读取异常时保持当前风速，移除「异常时强制全速」保护 | 探头掉线时不再突然全速；故障期间散热能力下降，建议在 HA 侧加温度告警 |
| 2026-07-01 | 全版本增加蓝牙代理（BLE Proxy） | 设备变成 BLE 网关，内存占用略增 |
| 2026-07-01 | CI 自动编译并发布 Release；仓库移除预编译固件 | 固件改从 [Releases](https://github.com/YUAXI/HomeAssistant-PWM-Fan-Controlx4/releases) 下载，不再随仓库分发 |
| 2026-06 | 温控参数（`T-Min`/`T-Max`/`F-Min`/`F-Max`）与温度源绑定支持掉电保持 | 重启后参数保留 |
| v2.0 | 新增 DS18B20 温度控制固件与 LD2402G 雷达固件 | DS18B20 版提供 4 路温度、16 个温控参数、5 秒本地闭环；雷达版额外提供存在检测与距离门限 |
| v1.0 | 提供 Web 界面、HTTP REST API、诊断实体 | 可脱离 HA 使用 |

## 升级注意事项

### 从「无 MAC 后缀」固件升级到当前版本

1. HA 中先**删除**旧的 ESPHome 条目（不要用「迁移」，否则会和新设备打架）；
2. OTA 或 USB 刷入新固件；
3. 重新添加设备，此时设备名带 MAC 后缀；
4. 仪表板/自动化里引用旧 `entity_id` 的地方需要重新指向新实体（可以先用「开发者工具 → 实体」搜索确认新 ID）。

### 从 `v1.0` 升级到 `v2.0`

- 硬件不同：v1.0 板子没有 1-Wire 与雷达接口，刷 v2.0 固件后温度/雷达实体永远是 `unknown`（功能不可用但不影响风扇）；
- 反之 v2.0 板子刷 v1.0 单核固件则只是少了扩展功能，风扇控制正常。

### 关于「同版本重刷」

Release tag 是构建日期，同一天多次触发 CI 会更新同一个 Release。若需要可追溯的版本，请记录下载时的 tag 与 `ESPHome 版本` 诊断实体。

## 兼容性矩阵

| 固件 | v1.0 硬件 | v2.0 硬件 |
|:-----|:---------:|:---------:|
| v1.0 双核 | ⚠️ 仅双核板 | ⚠️ 仅双核板 |
| v1.0 单核 | ✅ | ✅ |
